# Y-MAX

**YOLO-based Multimodal Analysis eXplorer** is a Python computer-vision application that detects people in images and videos using Ultralytics YOLO. It saves annotated results and lets you choose a model and confidence threshold.

## Requirements

- Python 3.13 or newer
- [uv](https://docs.astral.sh/uv/)

## Running Y-MAX

1. Clone or download this repository.

2. Open a terminal in the `Y-MAX` project folder.

4. Install the project dependencies:
   ```powershell
   uv sync
   ```
  
5. Start the program:
   ```powershell
   uv run python y_max.py
   ```

## Using the program

- Follow the menus by entering a number which corresponds to the option you want to select
- Press Enter at a supported default prompt to us the displayed default
- Type `back` at any menu or prompt to return to the previous menu or prompt
- For specific instructions, select `2. Read the instructions` in the Y-MAX main menu
